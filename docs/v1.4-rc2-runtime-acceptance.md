## 保留限制

- **H1／P1**：原生暫存仍是容量預留與輪詢後終止，不是寫入前的硬配額。
- 100 MP JXL 因 committed memory 不足尚未成功驗收。
- 乾淨 Windows 的 MSI 安裝、修復、解除安裝、升級與 SmartScreen 未驗證。
- SMB 實際斷網與非本機 NAS 未驗證。
- 執行檔與 MSI 未簽章。
- Portable ZIP 以「隨附條款、使用即同意」加上發行頁說明滿足 Microsoft 條款的「要求同意」，MSI 另有安裝時的明示同意；本文件不是法律意見。
