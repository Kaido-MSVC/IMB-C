# RC2 Microsoft Runtime 交付準備

本文件描述 Runtime 更新後的 RC2。更新前的版本（14.51.36247.0、五份 DLL、根目錄 `vcruntime140.dll`、先同意再交付的好友流程）已由本文件取代；歷史核對見 [RC2 授權合規複查](v1.4-rc2-license-review.md)。

## 隨包檔案

| 封包路徑 | REDIST 類別 | 版本 |
| --- | --- | --- |
| `ImageMagick/MSVCP140.dll` | C++ 標準函式庫，x64 CRT（Microsoft.VC145.CRT） | 14.52.37029.0 |
| `ImageMagick/vcruntime140.dll` | x64 CRT（Microsoft.VC145.CRT） | 14.52.37029.0 |
| `ImageMagick/vcruntime140_1.dll` | x64 CRT（Microsoft.VC145.CRT） | 14.52.37029.0 |
| `ImageMagick/vcomp140.dll` | x64 OpenMP Runtime（Microsoft.VC145.OpenMP） | 14.52.37029.0 |

來源是 Visual Studio Community 2026 Stable（`VisualStudio.18.Release`）default toolset 14.52.37025 的 `VC\Redist\MSVC\14.52.37025\x64`，非 preview（同一安裝的 preview toolset 14.53 未使用），也非 `debug_nonredist` 或 `onecore`。四份都是 Microsoft 簽章有效、附時間戳、非 Debug、非 PreRelease 的未修改原檔。版本與隨包二進位中最新的連結器 14.52 相同，符合 Microsoft「Runtime 不得舊於建置工具」的部署要求。逐檔來源、簽章與新舊雜湊見 `licenses/microsoft/RUNTIME-VC-UPDATE-1.4.0-rc.2.json`。

程式根目錄不再隨附 `vcruntime140.dll`：`imb-c.exe` 與 `imb-c-cli.exe` 以靜態 CRT 建置，不匯入任何可再散布的 Microsoft DLL。

## 權源與條款

- **發行者**：依 Visual Studio Community 2026 條款（`VS2026_Comm_ENU.1033`，2025-10-01）第 5 節 Distributable Code 及 REDIST 清單再散布。[Community 2026](https://visualstudio.microsoft.com/license-terms/vs2026-ga-community/) · [REDIST 清單](https://learn.microsoft.com/en-us/visualstudio/releases/2026/redistribution)
- **接收者**：依 Microsoft Visual C++ V14 Redistributable and Runtime 條款（`Cpp_v14_ENU.1033`，2025-10-01）安裝及使用；接收者條款不授與再散布權。[VC Runtime 條款](https://visualstudio.microsoft.com/license-terms/vs2026-ga-visualcpp-v14-redist-runtime/)

**Microsoft 條文明確要求**（Community 2026 §5）：DLL 不得修改；須隨具有重要主要功能的應用散布；要求散布者及外部終端使用者同意保護程度不低於 Microsoft 條款的條款；發行者對 Microsoft 負擔補償義務；不得散布 Debug、preview 或 Unreleased 元件，也不得以 Microsoft 商標暗示背書。條文**沒有規定**同意的形式、時點或紀錄方式，也沒有要求在下載前逐人取得同意。

## IMB-C 的條款交付方式

- **MSI**：標準授權對話方塊顯示 `RUNTIME-RECIPIENT-TERMS.md`（固定版本 `IMBC-RUNTIME-1.4.0-rc.2-r3`，含官方全文），須勾選同意才能安裝；靜默安裝須提供 `ACCEPTTERMS=1`。
- **Portable ZIP**：條款全文與官方 DOCX 隨包提供；條款載明使用即表示同意。
- **發行頁**：寫明封包含 Microsoft Visual C++ Runtime、下載或使用即表示同意，並附條款連結。

GUI 與 CLI 不顯示條款視窗、不記錄同意狀態，也不因此限制轉檔。先前 RC2 建置的首次啟動同意視窗、CLI `runtime-terms` 指令、`--accept-runtime-terms` 參數、同意紀錄與 runtime 閘門已移除；使用者既有的 `runtime-terms-acceptance.json` 不再讀取，也不刪除。GUI／CLI 仍以靜態 CRT 建置，DLL 搜尋只允許 System32，隨包的 Microsoft DLL 只由 ImageMagick 引擎從已驗證的 runtime 快取載入。

使用者操作與發行者交付說明見 [`RUNTIME-HANDOFF.md`](../RUNTIME-HANDOFF.md)。
