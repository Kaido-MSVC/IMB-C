# IMB-C 1.4.0-rc.2 修正審查

本文件保留第三輪前的審查結果。最終候選的執行邊界與驗收狀態見 [RC2 已知問題](v1.4-rc2-known-issues.md)。

本輪範圍是既有 Windows Rust／Slint 桌面應用程式的 RC1 審查缺陷修復，不是函式庫 API 改版、完整沙箱重建或新格式開發。Rust 1.100.0、edition 2024；第三方鎖定版本不變。保留原有未提交開發工作、歷史候選及私人素材；沒有提交、推送、建立 Tag、公開發布或製作 MSI。

## 逐項結果

| 發現 | RC2 處理 | 來源與驗證依據 |
|---|---|---|
| H-1：檔案系統保護能力 | 已加工作路徑守門與警告；全機隔離仍有限制 | filesystem_safety.rs 以實際 File 控制代碼查磁碟區資訊，GetVolumePathNameW／GetDriveTypeW 辨識遠端，遠端才允許 root API 後備。無 ACL 與未知本機拒絕；NTFS、ReFS、SMB 分別處理。engine.rs 一般轉檔與 JPEG ↔ JXL 路徑都在原生解析前檢查。實際 NTFS／exFAT 只讀查詢、SMB 補測及能力模擬分開記錄。無法保護其他已掛載可寫磁碟，見已知問題 |
| H-2：磁碟硬配額 | 保留 P1 | 本輪未更動磁碟／串流上限、預留與監控。已具體揭露預留與上限不相等、監控涵蓋範圍及記憶體映射盲區，沒有用危險的寫滿測試或未驗證大型重構宣稱解決 |
| H-3：完整 Low IL 隔離 | 保留 P1 | Job 生命週期不是讀取／網路／跨工作存取隔離。現有最小 policy、Low IL、權杖、受控暫存與來源唯讀保留，不能宣稱安全處理任意惡意圖片 |
| M-1：AVIF JSON 成功誤導 | 已修正 | iat.rs 使用型別化 Verdict；缺少 pixel_verified=true 的 AVIF 正規化 code=2，tool_exit_code 仍可為 0，verified=false。CLI 舊轉檔欄位不改含義，新增驗證欄位；單元與 Release 假工具案例涵蓋成功、差異、解碼失敗、無法判定及缺少工具 |
| M-2：記憶體預留假設 | 已修正 | 初次明確傳遞 job_commit_mib=1024、buffer_mib=64；重試合併白名單設定，範圍分別不超過 4096／256 MiB。預留與外層 Job cap 均為 job + buffer + 128 MiB，初始 1216、最高 4480。版本探測 cap／預留 128 MiB。不是僅相信外部工具預設；真實 Job 拒絕超額配置與 iat 巢狀生命週期均補測 |
| M-3：明確要求工具不可用 | 已修正 | CLI iat_requested／iat_available 與 unavailable 物件分開。缺少或版本不合不回退；保留核心轉檔與輸出，程序退出 2。轉檔錯誤優先 1、取消 130。Release CLI 核對 JSON 與實際輸出 |
| M-4：佇列滿載 | 保留有界策略並改善可見性 | 容量 8、單一消費者、不阻塞最多兩項轉檔。滿載仍不自動補排，明確未檢查警告保留；介面補已完成／已排入分母。既有容量、消費者失敗與兩工作屏障測試，加真實轉檔／iat 消費者等待補測。不是每檔必定驗證的保證 |
| L-1：授權橫幅混入錯誤 | 已修正 | 根因是自有 runtime 在 stderr 固定輸出授權資訊。僅剝離起訖完整、位於開頭且每行符合已知白名單的資訊字首；保留真正診斷、未知與不完整訊息。stderr 仍有界讀取，錯誤摘要最多 4096 字元。原生檔案與套件內授權資訊不改；單元及實際壞 IDAT 回歸 |
| L-2：CMYK → AVIF 提示 | 已修正 | 既有安全拒絕改在色彩預檢直接說明 CMYK 無損不支援，不再僅顯示底層色度平面錯誤；格式回歸維持拒絕 |
| L-3：stdout 關閉 panic | 已修正 | Help／Version 使用 Write 並處理 BrokenPipe，診斷寫入錯誤不 panic。Release CLI／GUI 子系統的已關閉 pipe 實測沒有退出 101 |
| L-4：Help 優先順序 | 已修正 | --help 在 -- 之前優先，包括 convert a.png --help；-- 之後仍當作檔名。GUI Help 使用正常資訊圖示。單元及 Release CLI 回歸 |
| L-5：非 UTF-8 路徑 | 已修正 | 位置參數保留 OsString，實際存取不經 lossy；JSON 顯示欄位保持相容並附可逆 input_wtf16_hex／output_wtf16_hex，避免顯示碰撞。Windows 孤立 surrogate 單元與真實檔名回歸 |
| L-6：DLL 搜尋 | 部分緩解，保留限制 | /DEPENDENTLOADFLAG:0xA00 與 SetDefaultDllDirectories(APP_DIR | SYSTEM32) 排除預設 CWD／PATH。因 Portable 需隨附 VCRUNTIME140，未使用只允許 System32 或改 CRT；應用程式目錄的同使用者 DLL 置換風險仍在。PE 與實際 Release 啟動核對 |
| L-7：iat 偏好設定路徑 | 已修正 | GUI 以原始 PathBuf 持有與啟動，顯示字串不回寫路徑；偏好設定 w16: 格式保存完整 UTF-16，同時能讀取舊 UTF-8 hex。單元涵蓋 surrogate 與舊設定 |
| L-8：路徑 TOCTOU | 延後，已揭露 | 同使用者能替換來源／輸出／工具；未將 File ID、SHA-256 或工具簽章繫結到結果。僅以路徑當時內容驗證；不是權限提升，也不冒稱已完全修復。完整身分繫結需另行設計與回歸 |
| L-9：轉檔與驗證進度 | 已修正 | 轉檔進度仍表示轉檔；iat 顯示完成／排入分母，批次結束等待消費者退出。用絕對接受數與 UI max 防止消費者先回呼造成分母倒退或重複增加 |
| L-10：文件／版本／換行 | 已修正 | README、CLI 契約與本候選已知問題修正安全界線；runtime 授權文件標頭改 RC2 並說明原生基線不變。新封包 checksum 寫 LF，歷史 RC1 文件與封包原樣保留 |
| L-11：無環境測試假通過 | 已修正本次指出入口 | v14_runtime_formats 明確標 ignored，另在有環境時實際執行。其餘環境相依入口依既有 ignored 分類，未測不算通過 |

## 生命週期與安全條件

iat 繼續以 CreateProcessW 的 JOB_LIST 原子納管，外層獨立 Job 設 KILL_ON_JOB_CLOSE、不允許 breakaway、不加入 ImageMagick Low IL Job、不增加會破壞子 Job 的 UI 限制。新增 Job 記憶體上限，不修改 iat 自己建立 worker Job 的相容規則。正常、逾時、取消、崩潰、啟動失敗均走等待／停止；確認整棵程序樹 active=0 才放掉記憶體預留。未知停止狀態保留資源，不冒然清理。

保留 persist_noclobber、read_bounded、retry_limits 白名單、PNG／ICC／CICP 邊界、最小權限 policy、偏好設定範圍、跨執行個體存活與 File ID 清理規則。沒有新增來源寫入或以驗證失敗刪除輸出的分支。

## 依賴與略過入口

Cargo.lock 相對本輪開始僅應用程式版本更新。cargo audit 仍有 7 項間接停止維護依賴、0 已知漏洞；依賴鏈與替代方案沿用未改變的 RC1 分析：bincode 2.0.1（選用未啟用，替代 postcard／wincode 等）、chrono 0.4.45（Slint Windows 日期時間，替代 jiff／time）、pin-utils 0.1.1（proc-macro 建置，替代 core::pin::pin!／pin-project）、ttf-parser 0.25.1（Wayland，替代 skrifa）、zbus_names 4.3.5／zvariant 5.15.1／zvariant_derive 5.15.1（Unix 無障礙，替代 zbus 6／zgvariant）。不為消除維護警告在 RC 階段強改上游相依。

RC2 為 53 個獨立 ignored 入口、五個二進位入口中 252 次 ignored：34 runtime（170 次）、2 SMB（10 次）、1 私人 PSD（5 次）、3 iat／佇列（5 次）、9 子程序輔助（42 次）、2 大型量測（10 次）、1 提升權限（5 次）、1 維護（5 次）。本輪實際執行結果見驗收報告；9 個輔助入口由父測試依需要執行，不獨立計通過。未重跑大型量測、未提升權限、不執行無必要的全帳本維護。
