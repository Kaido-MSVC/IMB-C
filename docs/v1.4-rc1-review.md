# IMB-C 1.4.0-rc.1 最終審查

## 程式與安全界線

本輪閱讀現有 v1.4 測試報告、前輪修復差異與目前工作樹，沒有重新開發 Phase 0–4。iat 外層 Job 在 CreateProcessW 時以 JOB_LIST 原子納管，設定 KILL_ON_JOB_CLOSE、不允許 breakaway、不加 UI 限制；iat 自身的 worker Job 可巢狀運作。繼承清單只有標準串流，不包含 Job 控制代碼。原生程序樹 active=0 後才離開 run 並釋放記憶體預留；無法確認停止時保留預留及受控暫存，留給執行個體結束與下次啟動處理。

佇列僅一個消費者、8 項等待；提交採 try_send，容量不受檔案數無限增加。轉檔已發布且寫入控制代碼關閉後才提交；批次先等轉檔池返回，再斷開 sender 並 join 消費者，最後才結算報告。取消旗標同時傳入引擎與 iat；排隊項目會回報取消，不重新啟動工具。這個順序沒有消費者反向等待轉檔工作才能釋放的鎖，未發現正常路徑死鎖或提前結算。程序 panic 的消費者錯誤有 join 回報，不能當成成功驗證。

CLI 與 GUI 共用引擎、記憶體預留與清理。受控目錄記錄擁有者日誌、volume／File ID；存活執行個體由鎖保護，回收拒絕相對／穿越路徑與重新解析點，並以原始控制代碼刪除。iat 目錄為了報告原子重新命名只增加 WRITE sharing，仍禁止 DELETE sharing；未放寬 ImageMagick 工作目錄。iat 預設停用且 Medium IL 的殘餘風險已標明。

目前兩項 P1 的觸發、影響、緩解與發布界線詳列於已知問題。本輪沒有以大型未驗證重構取代風險揭露；在受信任圖片、個人或少量分享範圍沒有新增阻斷問題，不能據此核准完整沙箱或公開不信任圖片服務。

## 7 項停止維護依賴

以下全是間接依賴，Cargo.toml 未直接宣告它們。本輪 cargo audit 使用更新的公告資料庫，未報告已知安全漏洞；維護警告不等於已確認可利用漏洞，也不保證原生 runtime 沒有未知漏洞。

| 套件與版本 | 目前依賴鏈及影響範圍 | 替代方案與 RC1 決策 |
|---|---|---|
| bincode 2.0.1 | Cargo.lock 與解析圖含 typed-index-collections → i-slint-compiler 的選用 bincode 功能；Windows 及 all-target cargo tree 沒有啟用鏈，typed-index-collections 未開 bincode 特性，不能因解析圖含節點就稱已編入本候選 | 上游可評估 wincode、postcard、bitcode 或 rkyv；格式／契約不同，應由使用它的上游移轉。RC1 不強行覆寫相依 |
| chrono 0.4.45 | Slint → i-slint-core 日期／時間內建功能；在 Windows 執行期依賴鏈，並非圖片解碼器 | 上游建議 jiff 或 time；應等待或評估 Slint 支援的遷移。RC1 不在版本凍結時替換整套 GUI 相依 |
| pin-utils 0.1.1 | Slint macros → spin_on；Windows proc-macro 建置鏈，非部署時圖片解析路徑 | 區域 pin 可用 core::pin::pin!；投影可用 pin-project／pin-project-lite，由上游建置工具替換 |
| ttf-parser 0.25.1 | winit → sctk-adwaita → ab_glyph → owned_ttf_parser，屬 Wayland 視窗裝飾；Windows x64 cargo tree 無啟用鏈 | 維護中的 skrifa／fontations；由上游調整，不增加本候選 Windows 相依 |
| zbus_names 4.3.5 | AccessKit Unix／AT-SPI／zbus 鏈；Windows x64 未啟用 | zbus 6 names 模組；上游 Linux 無障礙套件遷移 |
| zvariant 5.15.1 | 同上，Unix D-Bus／GVariant 型別；Windows x64 未啟用 | zbus 6 wire；若需要 GVariant 則評估 zgvariant |
| zvariant_derive 5.15.1 | 同上，Unix 衍生巨集；Windows x64 未啟用 | zbus 6 提供相應巨集；需由上游協調版本 |

Cargo.lock、目標依賴樹與 Windows 實際建置分開評估，沒有為了消除警告移除無障礙功能或放寬驗證。chrono 的公告網頁在查詢時無法存取，以上維護狀態及替代方案採本輪 cargo audit 公告資料庫快照，並已以目前 Slint 程式確認日期時間用途。

公告：[bincode](https://rustsec.org/advisories/RUSTSEC-2025-0141.html)、[chrono](https://rustsec.org/advisories/RUSTSEC-2026-0543.html)、[pin-utils](https://rustsec.org/advisories/RUSTSEC-2026-0441.html)、[ttf-parser](https://rustsec.org/advisories/RUSTSEC-2026-0192.html)、[zbus_names](https://rustsec.org/advisories/RUSTSEC-2026-0371.html)、[zvariant](https://rustsec.org/advisories/RUSTSEC-2026-0370.html)、[zvariant_derive](https://rustsec.org/advisories/RUSTSEC-2026-0372.html)。

## ignored 測試計數

前輪 241 是不同二進位入口重複包含共用測試的次數，不是 241 個獨立案例；最後新增佇列整合案例後，現在為 51 個獨立入口、242 次 ignored。32 項一般 runtime、2 項 SMB、1 項私人素材、3 項 iat／佇列專項，本輪在單一 GUI 測試入口補跑，38 項全部通過，0 失敗，避免五個入口重跑相同案例。9 項是父測試啟動的子程序輔助入口，不單獨算通過；另外 2 項大型量測、1 項需既有提升權限、1 項維護專用入口仍依條件略過。

| 分類 | 獨立入口 | 五入口中的 ignored 次數 | 本輪處理 |
|---|---:|---:|---|
| 一般 runtime | 32 | 160 | 補跑 |
| 私人 PSD 素材 | 1 | 5 | 使用既有唯讀素材補跑，前後檔案屬性及雜湊核對 |
| SMB／UNC | 2 | 10 | 使用本機專用 SMB 目錄補跑，不代表所有 NAS |

| 已提升權限 | 1 | 5 | 未提升權限，不計通過 |
| 維護專用 | 1 | 5 | 不需要回收整個測試帳本，未執行 |

## 版本及封裝

Cargo／GUI／CLI 使用 1.4.0-rc.1；Windows 固定四段版本為 1.4.0.1，預發行旗標啟用。GUI 與 CLI 均附 VERSIONINFO 與各自的 OriginalFilename。Cargo、Windows SDK 版本資源與封裝工具已查閱對應文件，並以建置、版本查詢及實際啟動驗證。

Portable 和 Source 以本輪來源及新建置的執行檔重新封裝，不改名沿用 dev ZIP。未變動的 runtime、第三方條文與對應來源是經雜湊核對的固定輸入；不重建既有 native runtime。私人 iat、文件、素材、PDB、本機證據與歷史內部文件均不納入公開候選。
