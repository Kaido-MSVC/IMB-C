# IMB-C 1.4.0-rc.2 來源重建說明

來源包的 source 目錄含本候選實際建置的 Rust／Slint 程式、Windows 資源、Cargo.lock、測試與公開建置腳本；native-materials/licenses 含第三方條文、署名、原生對應來源及建置材料。沒有私人 iat、私人圖片、PDB 或本機帳本。

## 應用程式

請在新解壓的 source 目錄建置，保留既有正式版、工作目錄與封包。

需要 Windows x64、Rust 1.100.0 MSVC toolchain、MSVC C++ build tools 與 Windows SDK resource compiler。進入 source 目錄執行：

```powershell
cargo build --locked --release --bin imb-c --bin imb-c-cli
```

相依版本由 Cargo.lock 固定。第一次建置需要已有相依快取或可存取 crates.io；本來源包沒有宣稱包含全部 Rust 套件原始碼或能在空快取離線建置。build.rs 會以 SDK rc.exe 分別建立兩個執行檔的圖示及版本資源。

GUI 與 CLI 必須以靜態 CRT 建置。`.cargo/config.toml` 已為 `x86_64-pc-windows-msvc` 設定 `-C target-feature=+crt-static`；若改用 `RUSTFLAGS` 或 `CARGO_ENCODED_RUSTFLAGS`，它們會覆寫 config，必須自行加入同一旗標，否則 build.rs 會中止建置。這樣兩支程式就不依賴可再散布的 Microsoft DLL，隨包的 Microsoft DLL 只由 ImageMagick 引擎載入。建置後可用 `dumpbin /dependents` 確認沒有 `VCRUNTIME140.dll`、`MSVCP140.dll` 或 `api-ms-win-crt-*`。條款全文 `RUNTIME-RECIPIENT-TERMS.md` 只作為封包文件提供，不編入程式。

## 執行期

Rust EXE 之外仍需要同版 Portable 內的 ImageMagick、JXL 與執行期 DLL。只使用本 RC2 Portable 或已符合 RUNTIME-MANIFEST-v1.4.json 的輸入，將這 58 個項目依清單複製到 target/release，並在複製前後以 SHA-256 核對；不要複製 Portable 內的舊 EXE 覆蓋新建置的 EXE。清單沒有列入的執行檔或外部工具不得自動帶入。

RC2 的 Runtime 更新（14.51.36247 → 14.52.37029，移除根目錄 `vcruntime140.dll`，59 → 58 項）由 `scripts/update-rc2-vc-runtime.py` 完成：先以舊清單核對已驗收的 RC2 stage，再只從 Visual Studio Stable default（非 preview）toolset 的 `VC\Redist\MSVC\<version>\x64` 取得四份 DLL，核對版本、非 Debug／PreRelease 與 Microsoft 簽章，並確認版本不舊於所有隨包二進位的連結器版本。來源與新舊雜湊記錄在 `licenses/microsoft/RUNTIME-VC-UPDATE-1.4.0-rc.2.json`。

`scripts/build-v14.ps1` 是從 v1.3.3 基線推導 v1.4 runtime 的歷史入口；它驗證的是更新前的 59 項清單，不適用於本次 Runtime 更新後的清單。原生 runtime 本輪只替換 Microsoft DLL，其他原生二進位沒有重建，其對應來源與歷史建置說明位於 native-materials/licenses；重新建置原生相依需要相應工具鏈與來源材料，不能只靠 Rust Cargo 完成。

RC2 執行檔使用 --remap-path-prefix 移除工作站路徑；重建者可自行設定其來源及使用者目錄對應。這不構成逐位元組可重現建置保證。封裝驗證記錄提供實際交付雜湊。

要採用自行修改的 LGPL 函式庫，依 [LGPL 替換與重建](../LGPL-REPLACEMENT.md) 的流程準備相符的 runtime 和內嵌清單。ImageMagick 的 JPEG XL 委派 DLL 與上游命令列工具各有獨立的 [固定來源與建置方式](v1.4-rc2-jxl-source.md)。

## 驗證

一般檢查使用 cargo fmt --check、cargo check --locked、cargo test --locked、cargo clippy --locked --all-targets -- -D warnings 與 cargo audit。runtime、SMB、私人素材及 iat 入口需要另外提供環境；條件不足時不得把 ignored 或內部略過算成已通過。RC2 的實際分類與結果見隨附審查及驗收報告。
