# IMB-C 1.4.0-rc.1 本機候選驗收報告

## 結論與來源

本輪沒有新的阻斷性缺陷，允許建立本機 RC1 Portable x64 與 Source 候選，並建議進入限定用途的正式 Release 驗收。尚未公開發布、建立正式 Tag、推送或製作 MSI。磁碟硬配額、Low IL 工作隔離及選用 iat 的 Medium IL 風險仍未消失，詳見已知問題。

版本為 1.4.0-rc.1，分支 dev/v1.4.0，基礎提交 1a199b7，加上保留中的未提交 v1.4 開發修改。本輪使用全新建置的 GUI／CLI，沒有改名、複製或沿用 dev ZIP。原有 runtime 與授權／對應來源材料作為固定輸入，59 項 runtime 與清單逐項核對。

技術環境：Windows x64、Rust 1.100.0 MSVC／edition 2024、Slint 1.18.1、Rayon 1.12.0、rfd 0.17.2、tempfile 3.27.0、serde_json 1.0.154、sha2 0.10.9。原生 runtime 為 ImageMagick 7.1.2-35 Q16-HDRI、libheif 1.23.7、libaom 3.15.2。Cargo.lock 只有本專案版本改動，第三方依賴圖不變。

## 未執行與風險

未重跑兩個大型量測入口，未進行提升權限、維護式全帳本回收、實際登出／關機、真實磁碟寫滿、200／400 MP 極端壓力、實體 NAS 斷線或乾淨主機 MSI 安裝／升級。這些沒有計為通過。本輪功能／安全測試沒有失敗。差異格式檢查曾指出 Windows 資源檔新加入前置處理指令的 CRLF 尾端空白；改為 LF 後檢查通過，SDK 重新產生的兩份資源與 RC1 已連結資源逐位元組相同，不改動執行檔。桌面工具曾有啟動時未回應及多視窗辨識不唯一，重新觀察／指定視窗後完成，未假裝操作成功。

既有兩項 P1 不阻止信任圖片、個人或少量分享範圍的本機 RC1，但仍阻擋完整沙箱、惡意工作互相隔離或安全處理任意不信任圖片的宣稱與發布範圍。正式 Release 前仍須依該範圍驗收，而不是把本候選當成已公開核准。

## 封裝後交付驗證

Portable 與 Source 重新建立後，檢查 ZIP CRC、逐檔內容雜湊、SHA256SUMS、私人資料排除及隔離解壓啟動。封裝後結果、檔案雜湊與最終啟動紀錄保留在交付目錄 RC1-DELIVERY-VERIFICATION.json；外層 SHA256SUMS.txt 列出實際 ZIP、報告及交付紀錄。內部 manifest 不包含自身。重建方式見 v1.4-rc1-build.md。
