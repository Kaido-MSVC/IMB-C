# DNG 唯讀候選評估

結論：本次不啟用 DNG coder。沒有重建、安裝或打包 LibRaw，也沒有擴大輸入白名單。

- **相容性**：LibRaw 官方提供 Windows x64／MSVC 組建，但不能據此推定與本專案的 CRT、ImageMagick 委派與 Low IL 啟動相容。DNG 的 CFA、線性／浮點、壓縮、白平衡及相機描述需要各自樣本；解碼原始感光樣本和產生顯示用 RGB 是兩個不同流程。
- **色彩與正確性**：LibRaw 用於擷取 RAW 與相關中繼資料，官方不以高品質顯像為核心範圍。不能把去馬賽克、白平衡或 tone mapping 後的 RGB 稱為原始 RAW 樣本無損。本版核心驗證以既有 RGB／RGBA 輸出為主，尚無 DNG 對照契約。
- **授權**：官方列出 LGPL-2.1 與 CDDL-1.0 可擇一；採用前須固定原始碼版本、選擇授權、盤點選用委派與額外套件，依專案授權規則從本機條文庫取得材料。此處不是散布核准。
- **部署體積**：本次沒有建置候選 DLL，不能提供可靠的新增 MB。應以相同 MSVC／CRT、固定功能集實際建置，量測 DLL、相應來源與授權材料的增量，不能拿官方完整 SDK ZIP 大小當安裝增量。
- **維護成本**：需要追蹤 RAW 解碼安全修補、相機／DNG 相容性、原生記憶體與暫存峰值，以及取消／Job／程序樹退出。本版不藉由啟用通用委派或外部 shell 取得 DNG 支援。

後續接受條件：固定版本與來源雜湊、選定授權及可重建部署、代表性 DNG 樣本前後雜湊不變、輸出色彩／精度契約、實際解碼與安全拒絕、取消和資源量測。未完成前保留不支援。

參考：[LibRaw 專案與授權](https://www.libraw.org/about)、[API 概覽](https://www.libraw.org/docs/API-overview.html)、[官方下載與修補紀錄](https://www.libraw.org/download)。
