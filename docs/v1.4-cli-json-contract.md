# IMB-C 1.4.0-rc.2 CLI JSON 契約

沿用逐檔 JSON lines 與既有轉檔欄位；新欄位均為附加。修正 AVIF 缺少像素實證時的 iat.code=0，以及明確要求工具卻回報 null 的錯誤行為。沒有要求 iat 時仍是 null。

## 轉檔與程序退出碼

逐檔 status=completed 只表示核心轉檔與既有引擎驗證完成並發布輸出；status=failed 表示轉檔失敗，error 記錄原因。來源唯讀，同名輸出仍編號，報告仍 persist_noclobber。iat 結果不會刪除來源或已發布輸出。

程序退出碼優先序：130=使用者取消；1=至少一個轉檔失敗；2=參數、環境、報告寫入錯誤，或明確要求的 iat 不可用／執行或協定錯誤；0=轉檔完成且無上述工具錯誤。正常完成的分析得到不同／無法判定／解碼無效／資源未檢查，不改寫轉檔 status，程序 0 不能當成無損實證。若需要確認外部驗證，必須判斷 iat.verified=true 或 verdict=verified。

## iat 物件

| 欄位 | 定義 |
|---|---|
| iat_requested | 此 CLI 批次是否明確指定 --iat；--no-iat 與 --iat 衝突會拒絕 |
| iat_available | 指定工具是否通過路徑、worker 與版本探測；執行中錯誤另外在 iat 回報 |
| iat | 未要求時為 null；明確要求但不可用時必有 unavailable 物件及原因 |
| iat.verdict | verified、different、indeterminate、invalid、not_checked、tool_error、unavailable、cancelled |
| iat.verified | 只有 verified 為 true；是給自動化使用的明確布林值 |
| iat.code | 正規化判定碼：0／1／2／3／4／5；沒有適用判定碼時為 null。只有 verified 可為 0 |
| iat.tool_exit_code | 工具原始退出碼；未啟動或報告協定錯誤無有效判定時可為 null |
| iat.status | completed 表示取得分析結果，不保證 verified；其他為 unavailable、failed、not_checked、cancelled |
| iat.message | 顯示及診斷文字，不作為程式判斷依據 |
| iat.avif_pixel_verified | 工具報告中的 AVIF 像素實證；true／false／null，不以 metadata 必要條件取代實證 |

AVIF 若工具退出 0 但 pixel_verified 不是 true，會正規化為 code=2、verdict=indeterminate、verified=false，tool_exit_code 仍為 0。這不是圖片損壞。缺少或不相容工具會是 unavailable；工具執行或報告錯誤是 tool_error。iat_available 反映探測結果，不能替代本次 verdict。

彙總報告保留 version、exit_code、results，另含 iat_requested、iat_available。成功逐檔結果也含這兩個欄位。來源或輸出顯示字串不改變實際存取路徑；input_wtf16_hex／output_wtf16_hex 用每個 UTF-16 code unit 四位十六進位，保留未配對 surrogate。還原後仍是原始 Windows 路徑，不以含替代字元的顯示文字重新存取。

外部比對依開啟時的路徑目標執行；尚未以發布時 File ID／SHA-256 鎖定其後整段排隊期間，也未鎖定外部執行檔雜湊。需要抵抗同一使用者主動替換檔案的證據鏈時，這是已知限制，不能把本欄位當成簽署的發布來源證明。
