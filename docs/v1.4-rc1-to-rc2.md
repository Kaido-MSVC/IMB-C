# IMB-C RC1 → RC2 修正摘要

版本由 1.4.0-rc.1 更新為 1.4.0-rc.2。重新建置應用程式與候選封包；原生 runtime 基線及 policy 雜湊保持不變，沒有新增格式、降低安全限制或改動 RC1 封包。

- CLI 將轉檔完成與 iat verdict 分開。AVIF 無像素實證時 code=2、verdict=indeterminate，另保留 tool_exit_code=0；只有 verified=true 表示已證實。沒有要求 iat 仍為 null；明確要求而工具不可用時輸出 unavailable 物件並退出 2，保留圖片輸出。
- iat 明確傳遞初始資源上限及重試合併參數，依實際上限預留跨執行個體記憶體，外層獨立 Job 強制限制 commit，保持完整退出後才釋放。
- 來源／輸出先查實際檔案系統能力；無 ACL 的 FAT／exFAT 安全拒絕，未知本機能力拒絕，其他支援 ACL 的檔案系統與 SMB 明確警告。既有 NTFS 暫存規則保留。
- 精確辨識自有 runtime 的已知 LGPL 訊息字首，錯誤畫面保留實際診斷、未知 stderr 與截斷資訊；原始原生訊息及隨附授權資訊沒有移除。CMYK → AVIF 無損改以明確提示拒絕。
- Help、Version 的 stdout 提早關閉不再 panic；convert 參數內的 --help 優先顯示說明（-- 之後仍是檔名）。非 UTF-8 位置參數與 JSON 可逆 UTF-16 路徑欄位、iat 路徑偏好設定修正。
- 增加 DLL 預設載入路徑限制與驗證完成／排入分母；runtime 相依測試列為 ignored，另以明確環境執行，不再列入無環境通過數。
- 修正本輪文件版本、檔案系統安全說明及新封包 SHA256SUMS 的 LF。保持既有 persist_noclobber、policy、來源唯讀與輸出保留。

保留：硬磁碟配額、完整 Low IL 工作隔離、有界佇列滿載不自動補排、同使用者路徑置換競態，以及應用程式目錄 DLL 信任要求。細節見 RC2 已知問題與逐項審查。
