## 2026-11-17 獨立審查修復與回歸

本節是本輪結果；後面的 Phase 0–4 表格與舊候選數字為前輪紀錄，未重新開發這些階段。分支維持 `dev/v1.4.0`，版本維持 `1.4.0-dev`。本輪沒有提交、推送、建立 Tag、發布或製作 MSI／正式封包；舊候選不代表本輪修正後的產物。

技術版本：Rust 1.100.0／edition 2024、Slint 1.18.1（winit／software）、Rayon 1.12.0、rfd 0.17.2、tempfile 3.27.0、serde_json 1.0.154、sha2 0.10.9；runtime 為 ImageMagick 7.1.2-35 Q16-HDRI、libheif 1.23.7／libaom 3.15.2。相依版本與 Cargo.lock 本輪未變更。私人整合指南、詳細契約與原始程序碼僅本機閱讀，沒有複製入公開來源。

### 本輪測試結果

- `cargo fmt --check`、`cargo check --locked`、`cargo clippy --locked --all-targets -- -D warnings` 通過；Release GUI／CLI 建置通過。
- `RUST_TEST_THREADS=1 cargo test --locked`：五入口分別 79／109／93／80／79 通過，合計 **440 次通過、0 失敗、241 次 ignored**；共用測試會在不同入口重複計數。一般套件沒有設定 runtime 的環境依賴入口仍會內部略過，不能當成實際格式驗收。最後新增的 ignored 佇列整合案例另外編譯與執行，不重跑已通過的一般案例。
- 實際外部程序專項：**2 通過、0 失敗**，包含逾時、取消、正常完成、持有主程序與 worker 控制代碼驗證退出，以及 IMB-C 被 TerminateProcess 結束後 Job 清理與具名暫存回收。
- 實際轉檔池／獨立驗證消費者：**1 通過、0 失敗**；消費者等待期間，兩個轉檔工作完成且交付已關閉的輸出，釋放後由真 iat 完成比對。另有滿載、消費者失敗與兩執行緒屏障測試。
- acceptance-v13：**14 PASS**，涵蓋 ICC、PQ／HLG 與兩組 JPEG 位元組往返。v1.4 runtime 主案例：**1 通過**，涵蓋 AVIF 真無損與 pixel_verified、JXL 有損／無損、PSD／PSB、8／16-bit、ICC、Alpha 保留及安全拒絕。沒有重跑前輪 16 MP／私人 PSD 大圖矩陣。
- CLI：**10 組通過、0 略過、0 失敗**（9 組主套件加 1 組舊版真 iat）；涵蓋批次、報告不覆寫、說明、錯誤組合、缺少／不相容工具、停用、真 iat 與特殊路徑。Release 另有 4 組參數煙霧檢查。
- GUI：agent-desktop 實際選取兩檔、輸出資料夾、指定並明確啟用 iat。先觀察到轉檔 2/2、iat 完成 1，最後 1 項無警告成功／1 項有警告成功、0 失敗、0 取消；兩個輸出保留，警告報告正確。帶圖片參數啟動 Debug GUI、未知選項啟動 Release GUI 通過。另以無主控台的 Release 入口執行 convert --help，實際確認訊息視窗顯示完整說明。
- `cargo audit --json`：**0 已知漏洞，7 項停止維護警告**；依本輪更新的公告資料庫，不把警告當漏洞，也沒有改動相依套件。
- 台灣繁體用語 default 檢查通過；僅檢查公開文件及擷取的繁中欄位，保留其他語系。
- **39 個來源**（包含兩份私人唯讀素材）大小、修改時間、SHA-256 前後一致；**59 個 runtime 項目**符合 v1.4 manifest。私人資料掃描公開候選來源為 0 命中，無 iat 執行檔或 PDB；歷史私人交接文件只保留本機並以 Git 文件白名單排除。

新增 **17 個測試案例與 1 個子程序輔助入口**；修改 **4 個既有測試案例與 1 個子程序輔助入口**。主要新增範圍為 iat 實際程序、設定 opt-in、顯示路徑、CLI 提示、回收與佇列。

### 初輪失敗紀錄與範圍

未隱藏初輪失敗：併行建置時，一項既有寫入上限測試超過 5 秒斷言，序列完整套件通過，未放寬該上限。另有既有匿名檔案測試在程序退出後立即列舉，碰到 Windows delete-pending 尚未消失；只增加 2 秒有界觀察，沒有替測試刪除檔案或放過殘留。完整套件之後通過。開發中的外部目錄鎖曾使 iat 原子 rename 報告失敗，已將必要 WRITE sharing 限定在 iat 目錄；引擎目錄限制未變。新增程序觀察測試曾因觀察控制代碼缺少 QUERY_LIMITED_INFORMATION 而無法讀 PID；僅修正測試查詢權限，最終實際程序專項 2/2 通過。所有原始失敗日誌保留在本機證據目錄。

沒有發現新的已重現安全或效能回歸；沒有宣稱全面效能保證。佇列滿載採明確「未檢查」降級，使用者若要求每檔外部驗證，須縮小批次後重新驗證，不能把滿載略過當成已驗證成功。

仍未解決：P1 磁碟硬配額與不同 Low IL 工作完整隔離；既有測試觀察沒有惡化，本輪未擴大重構。P2 部分 ICC／灰階編碼路徑仍安全拒絕。未執行實際登出／關機、200／400 MP、真實寫滿或極端壓力，也未做 MSI 安裝／升級或乾淨主機測試。

RC 判定：本輪 8 類修復已達本機功能 RC 的回歸條件；可進入標示上述 P1／P2 限制的 RC 準備，但不能宣稱完整沙箱或正式公開發布已核准。既有 Phase 4 封包不含本輪修正；若要交付 RC，須另以最終來源與公開白名單產生新候選並驗證雜湊，本輪沒有製作正式封包。

本輪修改：`.gitignore`、`README.md`、`RELEASE-CHECKLIST.md`、`docs/v1.4-development.md`、`docs/v1.4-test-report.md`；`src/cli.rs`、`src/controlled_temp.rs`、`src/engine.rs`、`src/i18n.rs`、`src/iat.rs`、`src/instance_ledger.rs`、`src/low_integrity.rs`、`src/main.rs`、`src/preferences.rs`、`src/process_guard.rs`、`src/regression_r2.rs`、`src/regression_security.rs`；新增 `src/validation_queue.rs`；`tests/test_cli.py`。除此以外的既有未提交 Phase 0–4 變更保留。

## 限制與未驗證範圍

- P1：原生暫存仍無檔案系統硬配額；監控、預留與 Job 都不等於磁碟硬配額。不同 Low IL 工作仍未完全互相隔離（M-2）。
- P2：部分 ICC 的 JXL 有損編碼會安全拒絕；灰階 JXL→WebP 的既有 ICC／精度限制保留。不能藉由丟 ICC 或放寬逐樣本驗證恢復表面相容性。
- AVIF 真無損僅接受目前已驗證的 8-bit RGB／RGBA 路徑，灰階會明確拒絕（編碼器不支援該 identity 路徑）；PSB 不自動接管超過 PSD 上限的輸出，未測超過 30000 邊長。未執行 200／400 MP、真實磁碟寫滿、極端壓力、實體 NAS／斷線。
- iat 一般取消／逾時會終止並等待主程序；沒有額外宣稱 IMB-C 被強制結束時外部 iat 的完整生命週期已驗收，也沒有宣稱其暫存納入引擎 Low IL 工作回收。
- 四語新字串與偏好設定有程式測試；agent-desktop 無法唯一辨識兩個未具名語言／外觀下拉欄位，因此沒有宣稱逐語系的完整 GUI 人工流程已驗收。已實測的 GUI 為繁體中文。
- DNG 未啟用，部署增量未量測。候選未簽章，未製作新 MSI，未發布或執行安裝升級驗收。

詳細本機證據保留在忽略追蹤的開發工作目錄；公開來源只含本報告摘要與產生式／既有公開測試素材。候選增加本次實際 Windows 建置圖缺少的 25 份 Rust 授權／署名材料，條文取自本機授權庫；保留原 native 來源／授權材料，不等同重新核准全部第三方的公開散布。
